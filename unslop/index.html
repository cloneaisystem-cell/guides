4 steps

  1. Install

    In a terminal (not inside Claude Code), one line at a time: 
    git clone https://github.com/heydamir/unslop
mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/
    On Windows PowerShell

    Same thing, written for PowerShell:

    git clone https://github.com/heydamir/unslop
New-Item -ItemType Directory -Force "$HOME\.claude\skills"
Copy-Item -Recurse unslop\skills\unslop "$HOME\.claude\skills\"
    For one project only

    Copy the skills/unslop folder into .claude/skills/ inside that project instead of ~/.claude/skills/. The skill then works only there.

    Prefer to let Claude do it?

    Open Claude Code in any folder and paste this. Claude shows every command before it runs it.

    Install the unslop skill for me. Show me each command before you run it.
Clone https://github.com/heydamir/unslop into a temporary folder, copy its skills/unslop folder into ~/.claude/skills/ (on Windows: C:\Users\<me>\.claude\skills\), check that SKILL.md is in the new unslop folder, then tell me to restart Claude Code.

  2. Restart Claude Code

    Close and reopen it so it loads the skill. Type / and look for unslop.

  3. Run it on your page

    Open Claude Code in your page's folder and type: 
    /unslop my landing page

    Only have a link? Type /unslop the hero of https://your-site.com. unslop saves a copy of the page and works on that, so you get a redesigned page in code to hand to whoever owns the site.

  4. Answer its questions

    unslop stops after the audit and a five-line direction (product, character, world, moments, signature) and waits for you. Read it, change a line if it's off, or say "go". It also asks you to confirm any claim it can't check, like "10x faster". The ones that aren't true get removed.

What it does

1. Audit. It lists every sign of the AI look it finds, one line each, with where it lives in your code. 2. It asks you first. The direction comes from your product, not from a trend, and nothing is edited until you answer. 3. Nine passes, in this order:

  1. Spacing
  2. Color
  3. Icons
  4. Copy
  5. Type
  6. Layout
  7. Details
  8. Visuals
  9. Motion

Spacing comes first because everything else reads differently once the rhythm is right. Your features, your content and the order of your sections stay, and it doesn't rename the product. If your page is already well designed, it says so, suggests two or three small refinements at most, and stops.

Optional: the story video (the clip at the top)

Add "and make the story video" to your command: /unslop my landing page and make the story video so I can post it. It builds a short square clip where the page cleans itself up, with red measurement lines. For that it needs Playwright and ffmpeg:

npm install -D playwright
npx playwright install chromium

ffmpeg has to be on your PATH too. On my slow PC the square render took 16 minutes, so ask for the video only when you want to post it.

The test: one sentence

To keep the test fair I didn't pick a bad site. I gave Claude (Sonnet) one sentence and changed nothing it built:

Build a landing page for my AI app that turns long videos into viral short clips.

ClipForge is a made-up app, and Claude picked the name. The page came back purple, glowing and gradient (left). Then I ran /unslop on it (right):

  • 26 tells found. The verdict was heavy slop, so it ran the full process.
  • It asked first. It stopped after the audit and wrote its direction: a cutting room, a printed transcript marked with a yellow marker under a desk lamp. I approved it as written.
  • It asked about the claims. "In minutes", "30 languages", "we don't train on your videos" and the Hook scores can't be checked from the page. It's a demo for a made-up app, so I confirmed them and they stayed.
  • The headline and every claim stayed the same. The copy that changed: the pill badge, the generic headings, the button labels and the "Thanks!".
  • The run took about 37 minutes of Claude time on my PC. The page went from 582 to 622 lines of HTML.
What each of the 9 passes changed on my page
  1. Spacing: everything on the 4 px grid, and one padding for the cards in a row.
  2. Color: the violet gradients, glows, washes and glass went. One warm graphite ramp, with the marker yellow only on the marked sentence, the selected clip and the focus ring.
  3. Icons: six emoji, text ticks and "+" signs became one line-icon set.
  4. Copy: the pill badge went, three button labels became one, "Thanks!" was fixed, the generic headings became specific ones.
  5. Type: IBM Plex Sans with Plex Mono for timecodes, weights 400 to 600, no uppercase labels.
  6. Layout: a left-aligned hero over a wide product view, and a menu button for phones.
  7. Details: corner radius by size, quiet hover and focus states.
  8. Visuals: the hero view became a marked transcript, a timeline and three clips with timecodes.
  9. Motion: one easing curve, no lift on hover, a tiny press effect.
Not perfect. No image tool was connected, so there is no generated hero picture and the three clip cards are plain surfaces. The hero is left-aligned with an empty right third, and that's the part I'm least sure about. Treat the result as a strong first pass and open it on your own phone before you ship it.

If something goes wrong

  • /unslop doesn't show up. Check that the file ~/.claude/skills/unslop/SKILL.md exists (not one folder deeper), then restart Claude Code.
  • It stops and asks questions. That is on purpose. Answer in the chat, or say "go" if you're happy with its direction.
  • The story video script stops on Windows with "chromium is undefined". That happened on my PC. Tell Claude: "Run an unchanged copy of story.mjs from a folder where Playwright is installed." The skill's own file stays untouched.
