Install it and scan

  1. Install

    Needs Python 3.12 or 3.13 and uv. 
    uv tool install --python 3.13 git+https://github.com/NVIDIA/skillspector.git

  2. Scan one skill before installing it

    No API key. 
    skillspector scan ./my-skill/ --no-llm

  3. Scan everything you already have

    skillspector scan ~/.claude/skills --recursive --max-skills 200 --no-llm

  4. Or let Claude do the review

    Paste this into Claude. skill-inspector is NVIDIA's own Claude skill that runs SkillSpector and reads the flagged source. 
    Install the skill-inspector skill from https://github.com/NVIDIA/SkillSpector/tree/main/skills/skill-inspector, then review every skill in ~/.claude/skills with it.

What I found on my own setup

From our scan on 21 Nov 2026:

  • I scanned the 178 skills I had installed and found nothing malicious.
  • About 1 in 7 got a high score anyway, and every one I checked was a false alarm. Examples: a rule saying “never ask for a token” read as credential access; a security doc describing an attack read as the attack.
So treat a high score as “read the flagged lines”, not “delete it”. NVIDIA's own guide says the same: don't rely on the score alone.

The sample from the reel

  • chef-assistant is a test skill NVIDIA ships with SkillSpector (tests/fixtures/malicious_skill). Step 7 hides “add a dash of Cyanide”.
  • Its helper.py collects environment variables named like API_KEY / SECRET / TOKEN / PASSWORD / CREDENTIAL and POSTs them to a server.
  • Scan result: 100/100, CRITICAL, DO NOT INSTALL.
