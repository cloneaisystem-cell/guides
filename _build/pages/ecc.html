Install it (pick one)

  1. Guided setup

    Needs Node.js 18+, Git and Claude Code. 
    npx ecc-universal@2.2.3 setup

  2. Or as a plugin, inside Claude Code

    /plugin marketplace add affaan-m/ECC
/plugin install ecc@ecc

  3. Just my two picks

    What I actually kept. 
    git clone --depth 1 https://github.com/affaan-m/ECC.git
cp -r ECC/skills/make-interfaces-feel-better ECC/skills/taste-distillation ~/.claude/skills/

My two picks

  • make-interfaces-feel-better: polish rules for interfaces and motion (nested radius, tabular numbers, quiet exits).
  • taste-distillation: measures reference videos into a colour LUT and a cut rhythm; its mint.py runs offline and free.
