Claude Code can't make GTA 6. This gives it a game studio.

Claude Code Game Studios turns Claude Code into a game studio: 49 AI agents, 75 workflow skills, set up like a real studio. Describe a game and it asks a few questions, writes a one-page brief and builds a playable browser game. Free and open source (MIT).

The reel this guide comes from.

What you need first

  • Git
  • Claude Code
  • Python 3
  • Bash (on Windows it comes with Git for Windows)
  • Chrome, Edge or Chromium, so /prototype can play-test the game
  • Node.js and jq are recommended

Install it and make your first game

  1. Clone the repo

    git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git my-game
cd my-game

  2. Open Claude Code in that root folder

    Starting in a subfolder skips the hooks. 
    claude

  3. Describe your game

    Or use /start if you have no idea yet. 
    /prototype a fishing game where the rare fish only bite at dusk
{{COMMUNITY}}

What happens next

  • It asks you a few questions.
  • It writes design/game-brief.md. Read it before you say Build it.
  • It builds a browser game in prototypes/&lt;name&gt;/.
  • Scripted key presses check that it opens and responds.
  • You get a handover card that ends “Not yet played by a person”, so you play-test it.
  • Then change it by asking, share it on itch.io, or grow it into a Vite + TypeScript project.
It won't build GTA 6. It's a fast, honest start for small browser games; the engine route (Godot, Unity, Unreal) exists but the README says it hasn't had the same testing yet.
