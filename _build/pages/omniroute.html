Set it up

  1. Install and start it

    This starts the local gateway and dashboard. 
    npm install -g omniroute
omniroute

  2. Connect providers in the dashboard

    Use your own accounts (Dashboard → Providers). Read each provider's terms; OmniRoute flags 12 as “avoid”.

  3. Run Claude Code through it

    The README's example is omniroute run claude --model openai/gpt-5.4. Or point any tool at http://localhost:20128/v1. 
    omniroute run claude --model <provider/model>

The fine print

From the README:

  • “~1.62B tokens/month” is an estimated total across third-party free tiers, “not a token grant from OmniRoute”.
  • You bring your own provider accounts.
  • Mistral alone is 1B of it (about 62%), then Nara 210M, LLM7 150M, xKiro 150M, Groq 30M.
  • Your prompts and code go to whichever provider answers.
My advice: fine for side projects and learning. For client or company code, check each provider's terms first.
